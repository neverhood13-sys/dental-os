# DentalOS

Веб-приложение для учёта стоматологической клиники.

## Стек

- React 18 + Vite + TypeScript + Tailwind CSS
- Supabase (Auth + PostgreSQL + RLS)
- FullCalendar
- jsPDF + html2canvas

## Возможности

- Авторизация через e-mail с ролями: главный врач, врач, администратор
- Тестовый вход без регистрации
- Клиники / филиалы
- Картотека пациентов, баланс, анамнез, ссылки на облака
- Зубная формула по ВОЗ (взрослая + детская) с контурами зубов
- Отсутствующие, молочные, сверхкомплектные зубы и имплантаты
- Drag-and-drop услуг из прайс-листа на зуб
- План лечения со статусами и цветовой кодировкой
- Прайс-лист с историей изменения цен
- Календарь месяц / неделя / день + экспорт .ics и ссылка «+ Google Calendar»
- Экспорт плана лечения в PDF, рассылка в Telegram / WhatsApp / E-mail
- Адаптивный интерфейс: desktop + mobile
